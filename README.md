# 在GPT打工的大肥鱼 🐟

**简体中文** · [English](README.en.md)

为了挣上一碗白饭，大肥鱼来到 GPT 打工，换上印着 ChatGPT Logo 的围裙，成为了你的桌面同事。

它认真接单，也惦记着开饭：收到任务先点头，工作时思考或翻书，完成后展示成果，偶尔还会叉腰傲娇。等待你的时候，它会玩玩具车、吃饭、打哈欠；实在无聊，就让一只黑鸟飞过头顶。

**在GPT打工的大肥鱼**是一款原生 macOS 悬浮桌宠，用 21 组动画把任务状态变成看得见的小动作。它住在其他普通窗口上方，陪你工作而不占用主界面；配套 Codex 插件将任务进度和回复摘要送到桌宠，白底蓝边的思考气泡让你随手查看消息、打开回复输入框。

**当前应用版本：0.3.1 · 插件版本：0.2.1 · macOS 13+ · 已验证 Apple Silicon**

![21 个动作预览](docs/previews/all-actions.jpg)

## 功能

- **21 组动画、132 张动画帧与 1 张待机图**，保留全部动作。
- 原生透明置顶窗口，可拖动，自动保存位置；支持 192 / 256 / 320 / 384 / 512 点大小。
- 接单、思考、研究、等待输入、完成、纠正、停止等任务状态，与对应动画关联。
- 空闲动作慢放并重复，触发间隔随持续空闲时间递增。
- 脑袋右上方的铃铛只在有未读消息时显示，读完隐藏。
- 白底蓝边思考气泡，长消息分页；气泡、图形、文字随桌宠同比例缩放。
- 气泡内直接回复输入框；双击桌宠将 Codex 桌面应用带到前台。
- 本地文件通信与 stdio MCP，无需启动网络服务。

## 安装与启动

目前采用源码构建。需要 macOS 13 或更高版本、Python 3，以及 Xcode Command Line Tools 中的 Swift 编译器。

```sh
# 尚未安装 Command Line Tools 时执行
xcode-select --install

# 获取源码
git clone https://github.com/Knox-zki/gpt-working-fat-fish.git
cd gpt-working-fat-fish

# 构建：同时运行内置状态机自检
python3 apps/dsl-pet/scripts/build.py

# 安装并启动（更新已有版本前，先从桌宠菜单退出）
mkdir -p "$HOME/Applications"
cp -R apps/dsl-pet/dist/DSLPet.app "$HOME/Applications/"
open "$HOME/Applications/DSLPet.app"
```

应用运行时不需要 OpenCV、图片生成服务或本地大模型。构建采用本地 ad-hoc 签名，尚未进行 Apple 公证。当前版本已在 Apple Silicon Mac 上验证；Intel Mac 和其他操作系统尚未验证。

默认画布高度为 256 点，主要动画帧为 512 × 512 像素；单车动画画布为 640 × 512 像素。Retina 显示使用原始图片，放大超过源图分辨率不会增加细节。

## 桌宠交互

| 操作 | 行为 |
| --- | --- |
| 单击桌宠 | 随机播放一次互动，最后一帧停留 1 秒，然后恢复默认姿势 |
| 双击桌宠 | 取消待执行的单击互动，将 Codex 桌面应用带到前台 |
| 拖动桌宠 | 移动并保存位置；空闲时重置计时 |
| 右键桌宠 / 菜单栏 DSL | 调整大小、预览 21 个动作、查看消息、暂停、隐藏或退出 |
| 左键点击消息气泡 | 翻到下一页；最后一页后再次点击关闭 |
| 右键点击消息气泡 | 关闭气泡 |
| 点击回复图标 | 打开同风格输入气泡；回车发送，Shift + 回车换行 |

快速连续单击最多保留一个待播放互动。中文输入法组合期间，回车用于确认候选字。发送失败时保留草稿；关闭回复框也保留草稿，退出应用后清空。

## 动画如何跟随任务

| 状态 | 动画与播放规则 |
| --- | --- |
| 接到任务 | 点头接单一次 → 最后一帧停留 1 秒 → 进入思考或研究 |
| 思考 / 工作 | 思考或翻书研究循环，每轮之间停留 1 秒；混合模式按权重选择并避免连续重复 |
| 需要用户输入 | 举手提问循环，每轮之间停留 1 秒 |
| 完成任务 | 展示成果 70%、叉腰傲娇 30%；播放完成后保持最后一帧 |
| 收到纠正 | 道歉一次 → 最后一帧停留 2 秒 → 工作 → 完成后认真修改并保持最后一帧 |
| 用户要求停止 | 立即中断，播放停止动作，然后保持最后一帧；迟到的完成信号不会覆盖它 |
| 点击互动 | 傲娇、转圈、探头、吃饭、灵光一闪等随机动作；播放一次、停留 1 秒后恢复默认 |
| 空闲 | 玩具车、吃饭、打哈欠、探头、黑鸟无语；较长时间空闲也可打瞌睡 |
| 出场 / 离场 | 单车入场、单车离场 |

空闲动作按原时长的 **1.5 倍慢放，每次播放 3 遍**，遍间停留 1 秒。首次等待 60 秒触发，之后从上一组动作结束起依次等待 **120、180、240 秒……**。点击、空闲拖动或插件活动事件会重置计时。完成和停止状态的终帧保持不会被空闲动作覆盖。

“下一步操作”包括：点击桌宠、打开桌宠回复框，以及 Codex 在前台时出现新的键盘活动。此时完成或停止姿势恢复默认；新任务则直接进入接单流程。

计时根据桌宠与插件活动，并不检测所有应用的全局鼠标操作。键盘活动检测只读取最近按键时间和前台应用标识，不读取输入内容；Codex 内的键盘快捷键也会算作新活动。

全部动作：傲娇、不开心、道歉、玩具车、吃饭、打哈欠、灵光一闪、转圈、头晕、黑鸟无语、点头接单、思考、翻书研究、举手提问、展示成果、认真修改、停止、打瞌睡、探头、单车入场、单车离场。

## 接入 Codex 插件

插件目录为 `plugins/dsl-pet`，本地插件市场配置为 `.agents/plugins/marketplace.json`。在支持本地插件市场的 Codex 客户端中添加该市场并安装 `dsl-pet`，然后重载插件。先将应用安装到 `~/Applications/DSLPet.app`；插件通过当前用户的 Home 目录定位控制桥。

插件提供三个 MCP 工具：

| 工具 | 用途 |
| --- | --- |
| `dsl_pet_event` | 发送任务状态或显示、隐藏、互动等事件 |
| `dsl_pet_status` | 查询桌宠当前状态 |
| `dsl_pet_notify` | 显示完成摘要、输入请求或其他通知 |

插件随附的 Skill 在用户选择桌宠陪伴后，于任务的重要节点发送事件。**它不自动监听所有聊天，也不保证每一个客户端生命周期事件都能触发动画。** 没有加载工具的旧聊天需要重载插件或重新打开会话。

也可以直接使用本地控制桥：

```sh
python3 apps/dsl-pet/scripts/bridge.py status
python3 apps/dsl-pet/scripts/bridge.py request_received --kind mixed
python3 apps/dsl-pet/scripts/bridge.py needs_clarification
python3 apps/dsl-pet/scripts/bridge.py task_completed
python3 apps/dsl-pet/scripts/bridge.py correction_received
python3 apps/dsl-pet/scripts/bridge.py user_stop
python3 apps/dsl-pet/scripts/bridge.py user_activity
```

## 消息与直接回复的边界

通知由插件主动推送摘要，桌宠最多保留 20 条消息，重启后清空。它不抓取聊天内容，也不接入 macOS 通知中心；当前未提供语音输入按钮。

直接回复仅支持本机 Codex 会话，需通知关联有效的本地会话 ID，且该会话具有当前桌面客户端 owner。用户主动点击发送后，控制桥通过客户端内部 IPC 将回复提交给原会话，沿用其模型、工作目录和权限。

该 IPC 并非稳定公开接口，客户端更新可能影响兼容性。发送失败会显示错误并保留草稿；超时结果可能不确定，应先核对原会话再重试。本地传输与界面检查已完成，真实模型收到回复并继续生成的完整流程尚待实际使用验证。

## 源码与素材

```text
apps/dsl-pet/
  Sources/           Swift / AppKit 应用与动画状态机
  assets/            独立素材包：21 组动画、待机图与时序 JSON
  scripts/           构建、MCP 控制桥与回复传输
plugins/dsl-pet/      Codex 插件与陪伴 Skill
.agents/plugins/     本地插件市场配置
docs/previews/       项目展示图片与动画
```

构建直接读取 `apps/dsl-pet/assets`，不依赖最初的素材仓库。围裙图案按确认样例局部替换为小号深蓝 ChatGPT Logo，放在画面左下方主布面，并根据姿势调整透视与遮挡。角色轮廓、帧尺寸、透明度和原动画时序均保留。

运行数据位于 `~/Library/Application Support/DSLPet`。构建产物、虚拟环境、开发阶段截图、旧版应用备份与原素材仓库不纳入本仓库。
