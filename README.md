# 在GPT打工的大肥鱼 🐟

**简体中文** · [English](README.en.md)

**这是一个面向 macOS 的 Codex 桌宠插件，配套独立的悬浮桌宠应用。** 它与官方 Pets 独立运行，可以同时使用；不会替换你选中的官方宠物，也不占用官方 Pets 的宠物选择位置。它是社区项目，并非 OpenAI 官方插件。

大肥鱼来到你的 Codex 打工赚大白饭，穿上印着 ChatGPT Logo 的 GPT 围裙，正式成为你的桌面同事。它认真接单，也惦记着开饭：工作时思考、翻书，完成后展示成果，偶尔还会叉腰傲娇。等待你的时候，就玩玩具车、吃吃饭，或者让一只黑鸟飞过头顶。

![大肥鱼的 21 个动作](docs/previews/all-actions.jpg)

## 它能做什么

- **陪你在 Codex 里工作**：用丰富的动画回应接单、工作、等待输入、完成和纠正等任务状态。
- **住在桌面上**：悬浮在其他普通窗口上方，可以拖动、调整大小，也可以随时隐藏。
- **把消息送到身边**：未读消息用小铃铛提醒，回复摘要显示在白底蓝边的思考气泡里。
- **方便继续对话**：通过气泡打开回复输入框，或双击桌宠回到 Codex。
- **闲下来也有小动作**：吃饭、玩具车、探头、打哈欠……共 21 组动画。

## 用一句话让 Codex 安装

在 **Mac 上的 Codex 本地聊天**中，复制并发送以下提示词：

```text
请帮我安装“在GPT打工的大肥鱼”Codex 插件：
https://github.com/Knox-zki/fat-fish-at-gpt

请读取项目文档，把项目下载到独立目录，构建并安装配套桌宠应用到
~/Applications/DSLPet.app，再注册本项目的插件市场并安装 dsl-pet。
保留我现有的官方 Pets、宠物选择和其他插件设置。
安装后启动桌宠，检查插件与桌宠是否连接成功，并告诉我是否需要重载 Codex。
```

当前支持 **macOS 13 及以上**，已在 Apple Silicon Mac 上验证。安装需要 Python 3 和 Xcode Command Line Tools；Codex 可以检查环境并引导你完成准备。目前采用源码构建安装，应用尚未经过 Apple 公证；Windows 和 Linux 暂不支持。

若你的 Codex 客户端不支持本地插件市场，安装可能无法完成；请让 Codex 明确说明缺少的支持。重载插件或重新打开聊天后，可发送：

```text
接下来的任务，请使用“大肥鱼”桌宠陪伴我，在重要任务节点更新动作，并在完成或需要我回复时显示消息气泡。
```

## 使用时的小提示

单击桌宠可以互动，拖动可以移动位置；右键菜单可调整大小、预览动作或查看消息。双击桌宠可以回到 Codex。

消息气泡可以点击翻页，读完后再点击即可关闭，也可以右键关闭。点击回复图标打开输入框；直接回复仅支持关联的本机 Codex 会话，目前仍属实验功能。

任务状态和消息摘要由插件在重要节点主动发送，**并非自动监听所有聊天**。当前没有语音输入功能；官方 Pets 仍可照常使用。
