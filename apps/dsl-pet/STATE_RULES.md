# 当前动画规则（0.4.0）

根据 Sources/Engine.swift 和素材 animations.json 核对。下列秒数为素材单轮时长，实际播放受定时器刷新影响。

| 状态 | 动画 | 播放规则 |
|---|---|---|
| 默认待机 | 静态待机图 | 保持默认姿势；到空闲触发时间再选动作 |
| 接到任务 | 点头接单 | 一次1.54秒，终帧停1秒，再进入工作 |
| 思考工作模式 | 仔细思考 / 敲电脑 / 拿本子认真推敲 / 掰手指数数 | 候选权重25:30:25:20；原思考1.62秒，新动作2.10秒；轮间停1秒，避免连续同动作 |
| 研究工作模式 | 翻书查资料 / 放大镜查资料 | 候选权重50:50；1.50/2.10秒；轮间停1秒，避免连续同动作 |
| 混合工作模式 | 上述六组工作动作 | 合并两组候选权重；避免连续同动作，每轮之间停1秒 |
| 需要用户输入 | 举手提问 | 每轮1.60秒，终帧停1秒，继续循环 |
| 完成任务 | 展示成果 / 叉腰傲娇 | 候选权重70:30；选一个播放一次（1.65/1.30秒），无限保持终帧 |
| 收到纠正 | 道歉 → 工作 → 认真修改 | 道歉一次1.62秒，终帧停2秒，然后工作；收到完成事件后认真修改一次1.64秒，无限保持终帧 |
| 用户要求停止 | 用户要求停止动作 | 立即打断当前动作，停止动作播放一次1.50秒，无限保持终帧；迟到完成事件不会覆盖 |
| 空闲动作 | 蹲着玩车车 / 吃白米饭 / 打哈欠 / 偷偷探头 / 黑鸟无语 / 长时间后打瞌睡 | 选一个动作，时长变成原来的1.5倍；同一个动作播放3遍，两次遍间各停1秒，第三遍后直接恢复默认 |
| 单击互动 | 傲娇 / 转圈 / 探头 / 吃饭 / 鬼点子 / 黑鸟无语 | 一次正常速度，终帧停1秒，回默认；快速点击最多排队一个互动；单击等待系统双击判定时间 |
| 双击 | 无新增动画 | 取消待执行单击，将GPT软件带到前台；当前动画状态保持 |
| 出场 | 骑着小单车出场 | 一次1.92秒，然后默认待机 |
| 隐藏 / 退出 | 收拾东西推单车离场 | 一次2.07秒，然后隐藏或退出 |
| 暂停 / 继续 | 当前动作 | 暂停冻结当前帧和计时；继续从原处恢复 |
| 手动预览 | 全部25动作 | 正常速度播放一次，保持终帧；不开心和坐地头晕目前只有手动预览入口 |

空闲首次等60秒；每组动作结束后分别等120、180、240秒，以此类推。点击桌宠、空闲时拖动或新任务/用户活动等插件信号重置计时。完成/停止终帧保持不会被空闲动作覆盖。计时依据桌宠及插件事件，未监听其他应用的全部键鼠操作。

| 随机场景 | 基准权重 |
|---|---|
| 首次空闲 | 玩车30、吃饭20、哈欠20、探头20、黑鸟10 |
| 累计默认待机超过90秒（通常从第二次空闲开始） | 玩车25、吃饭15、哈欠20、探头20、黑鸟10、打瞌睡10 |
| 单击互动 | 傲娇25、转圈15、探头25、吃饭25、鬼点子8、黑鸟2 |

权重在当前可选候选中归一化。空闲按组、互动按次避免连续重复；同动作有12秒冷却，候选不足时回退。完成允许连续同动作但仍考虑冷却，因此权重不等于每次固定概率。

接单/道歉期间若已收到完成信号，先遵守终帧停留，再播放一轮工作后展示完成动作。工作中的完成、需要输入或停止事件可打断当前循环。

通知、铃铛、气泡本身不驱动动画，插件需另外发送相应状态事件。铃铛位于脑袋右上方；全部已读后隐藏。

认真推敲与数数共用第1、2、5、6帧。重复的查资料事件不会重启动正在播放的放大镜动作。自行车篮中的筷子保留，电脑和放大镜随原自行车动画移动。
